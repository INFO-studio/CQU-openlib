# `updated` 与更新日志

核心判断：**读者在页面上看到的信息本身变了才动**

## 判定表

两列独立：

| 你做的事 | 改页面 `updated` | 写更新日志 |
| --- | --- | --- |
| 新增 / 更新 / 下线资源链接、教材、试卷 | 是 | 是 |
| 登记 / 兑现待办需求 | 是（待办页） | 是 |
| 改正文表述、结论、数据 | 是 | 是 |
| 新建一个有内容的页面 | 是 | 是 |
| 修渲染 bug（某语法不生效、内容显示错误） | 否 | 是 |
| 批量统一格式（图标换名、补行尾空格、缩进） | 否 | 否 |
| 错别字、标点 | 否 | 否 |
| 为配合解析器改动做的等价改写 | 否 | 否 |
| 重构、依赖升级、构建 / CI、测试、性能优化 | 否 | 否 |

修渲染 bug 改的是解析器而非页面内容，所以不动 `updated` 但写日志；批量改格式不能统一刷 `updated`，否则会废掉「编辑于」时间信号

## frontmatter

```yaml
---
updated: 2026-07-31
---
```

- 已有 frontmatter：把 `updated` 改为**当天** `YYYY-MM-DD` 字符串（不写时间戳）；无则文件开头补整块并空一行写正文
- 浏览器解析器识别 `updated`、`description`、`title`、`placeholder`：`description` 为可选短描述；`title` 省略用 H1、字符串自定义、`null` 只显示站点名 `CQU-openlib`；`placeholder: course` 注入课程占位正文
- 构建期另读取 `search.keywords` 与 `search.codes`，不渲染也不直接进全文索引（实现 `app/utils/docFrontmatter.ts`、`vite/searchContent.ts`）

### 不加 `updated` 的目录

- `public/doc/index.md`（首页不展示「编辑于」）
- `public/doc/contributor/**`（贡献者个人页）
- `public/doc/sundry/更新日志/**`

用户明确要求不动日期时跳过；拿不准先问，不默认加

## 更新日志

面向读者，只记录站点收录内容和读者可见呈现的变化。代码修复只写读者可直接观察的现象与结果，不得描述配置键、frontmatter、解析器、组件、依赖等内部实现（删掉内部细节后无读者可见变化就不写）

### 绝对禁止写入日志

- 管理页和站内工具路由（`app/routes/admin.tsx`、提交审核、表单后台）
- `public/doc/42/**` 的任何改动

### 同步修改三处

**1. `public/doc/sundry/更新日志/YYYY/YYYY-MM/YYYY-MM-DD.md`**

不存在则新建，无 frontmatter，一条一行，相对链接指向被改页：

```markdown
- 新增 [泌尿系统与疾病](../../../../course/泌尿系统与疾病.md) 页 `res: 教材-泌尿系统与疾病-第一作者-人民卫生出版社-第2版`
- 修复正文中形如 `8:00-8:30` 的时间被误认作图标、显示为灰色的问题，见 [新生指南](../../../../academic/入学必看/新生指南.md) 晨曦计划打卡时间
```

资源改动用 `res:` 无空格短横线简写，字段顺序同条目行：

```
res: 教材-书名-第一作者-出版社
res: 教材上册-自动控制原理-宋永端-机械工业出版社
res: 教材习题解答-离散数学-左孝凌-上海科学技术文献出版社
res: 期中试卷-MATH10822-2023秋-A-试卷+答案
```

兑现待办补一行 `完成`（序号格式见 [entry-formats.md](entry-formats.md)），同时**删掉** `sundry/待办事项/textbook.md` 该条并把待办页 `updated` 改当天：

```markdown
- 完成 [待办事项-教材需求](../../../待办事项/textbook.md) `legacy#134`
```

登记待办也要写日志（待办页无入口流量，日志会播报到 QQ 群），用 `书名-第一作者-出版社-ISBN` 不套 `res:`；提交者记入 `contributor/index.md` 纯名字，不写进待办条目：

```markdown
- 登记 [智能制造执行与决策分析](../../../../course/智能制造执行与决策分析.md) 教材需求 `智能制造系统感知分析与决策-胡耀光-机械工业出版社-9787111787433`，详见 [待办事项-教材需求](../../../待办事项/textbook.md) `#254ce080` @ 淮橘
```

资源日志用可读名，禁用 filekey；由贡献者提供时沿用资源页链接写 `@ [贡献者](贡献者页面.md)`（`@` 前后各一空格，禁写「贡献者是」），同贡献者多项可并列后统一署名：

```markdown
- 新增 [学术写作](../../../../course/学术写作.md) 页 `res: 教材-英语学术论文写作教程-史宝辉-中国人民大学出版社-9787300249636` @ [joker](../../../../contributor/joker.md)
```

**2. `public/doc/sundry/更新日志/index.md`**

- 顶部「最新更新日志：」链接改当天
- 对应「年 / 季度 / 月」tab 下补一行；新建 tab 顺序为**年升序、季度升序、季度内月份降序、月内日期升序**

**3. `public/doc/index.md`**

首页「公告」里 `[更新日志](…) / [YYYY-MM-DD](…)` 的日期链接改当天，不加 `updated`

当天已有日志时：确认第 2、3 处已指向今天则不再重复改，只追加第 1 处末尾
