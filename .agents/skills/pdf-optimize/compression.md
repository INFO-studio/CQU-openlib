# 压缩原理与调参

## 为什么不是「降 DPI + 压 JPEG」

扫描件可读性来自 DPI，降 DPI 等于砍清晰度。JPEG 的 DCT 编码压文字会在笔画边缘产生振铃和块糊；中文笔画密、字腔小，稍一模糊就糊成一团。

正确做法是分开对待两种内容：

- **文字**：保持原生 DPI（一般 300），局部自适应阈值转 1-bit，JBIG2 generic region 编码。体积小、边缘纯黑白，往往比原始灰度更锐。
- **图片**：连续色调区域（切片、超声、人像、渐变）单独裁出，JPEG 编码，可降到 150 DPI。

两者按 MRC（Mixed Raster Content）叠在同一页：正文层全页 JBIG2，图片区在正文层挖白，JPEG 补丁盖回原位。

## 低 DPI 扫描：二值化根本不该用

上面那套分层的前提是**原生 300 DPI**。150 DPI 的中文扫描不满足：一个字只有 ~20 px，笔画宽 1.5–2 px，**灰度的抗锯齿正是记录笔画边缘位置的那部分信息**，二值化必然把它丢掉。结果就是「对比度更高但更难读」——不是参数没调好，是信息不够。

新能源材料与器件（150 DPI，239 页，25.0MB）实测，同一页 `岩层中` 三字：

| 路径 | 体积 | 结果 |
| --- | --- | --- |
| 二值化 450 DPI k0.10（调到最优） | 18.2MB | 字形块状、边缘咬缺，读者不接受 |
| 灰度 150 DPI q80 | 40.9MB | 与源文件观感一致 |
| **不重编码，只清广告** | **25.0MB** | 像素逐张不变 |

结论：**只要文件已在预算内，就不要重编码**（见下方「何时根本不 run」）。判据不是体积。

### 判据是曝光，DPI 只是相关量

一开始我把界线画在「原生 300 DPI 才二值化」，机械设计基础（240 DPI）推翻了它：**240 DPI 二值化效果极好**，断笔 0.07‰ 比淡扫描在 600 DPI 上的 0.06‰ 相当，正文放大后比源灰度锐得多，体积 58.7 → 16.0MB。

差别在曝光。跑 `run` 前先量三个数（240 DPI 渲染，取几张正文页）：

| | 新能源材料与器件（别二值化） | 机械设计基础（该二值化） |
| --- | --- | --- |
| 墨核 p0.5 | **128** | **19–41** |
| 纸面 p80 | 254 | 255 |
| 墨覆盖 <200 | 10.2% | 5.5–7.4% |

**墨核灰度 100 以上就是曝光过亮的扫描**，笔画本身已经和纸面糊在一起，二值化只能在「丢细笔画」和「填字腔」之间选；墨核在 50 以下、墨覆盖 5–8% 的书，笔画和纸面界限清楚，一套默认参数就能切得干净。

顺带一条：这类曝光正常的书上 **`--sauvola-k` 默认 0.20 比 0.10 更好**（断笔 0.07‰ vs 0.11‰，且不粘连），继续加 `--bilevel-min-dpi` 到 480 也没有收益（0.08‰，体积 12.2 → 18.0MB）。降 k 是淡扫描的补救手段，不是普适改进。

只加可搜文本层、一个像素都不动：

```bash
pdfopt ocr 某教材.clean.pdf --out out/某教材.pdf
```

## 扫描太淡：用色阶，不要用阈值

`--text-contrast 0-100`（默认 0 关闭）。曝光过亮的扫描读起来发灰，量一下就知道有多淡：新能源材料与器件正文页墨核灰度 **128**，正常扫描应在 30 上下。

这是曝光问题，要用**色阶曲线**修，不是阈值：每个输入灰阶仍映射到不同输出灰阶，单调、不合并，**不可能切断笔画**——这正是它和 `--mode bilevel` 的本质区别。

锚点必须**按页从直方图量**（`Tone` 里的 `paper_pct` / `ink_pct`），不能给死数。固定色阶在淡页上过冲、在深页上无效，还会把字周围的柔光晕放大成 JPEG 可见的糊块。守卫：纸面亮度不足 200（封面、整幅照片）或墨纸差不足 32 时整页跳过——实测封面页 p80=57，曲线正确地没有生效。

代价是体积：拉伸对比度会连扫描颗粒一起拉伸。同书 150 DPI 灰度整页，239 页估算：

| `--text-contrast` | q | 体积 |
| --- | --- | --- |
| 0 | 80 | 33.8MB |
| 100 | 80 | 41.9MB |
| **100** | **70** | **36.4MB** |

**别去动 `paper_pct` 想压平纸面省体积**——压低锚点会让剩余区间斜率更陡，晕圈放大更多，实测 254→244 反而从 38.1 涨到 40.6MB。默认的 p80 既最鲁棒也最省。

### 加深必然连背透一起加深 → 配 `--drop-showthrough`

背面文字的镜像透印是真墨，只是不属于这一面。色阶曲线不认识这个区别，**斜率 2 会把 240 的透印压到 216，页面越深越脏**——新能源材料与器件前言页出现过这个回归。

好在两拨像素在灰阶上分得开，量一次就知道能不能切：该书前言页只有背透的下半页 p0.5=**240**，真正文墨核 **130**。

| `--drop-showthrough` | 白点 | 残留背透 | 正文墨像素 |
| --- | --- | --- | --- |
| 0 | 254 | 29.6% | 31.3%（含全部晕圈） |
| **20** | **235** | **0.07%** | 11.6% |
| 30 | 225 | 0.00% | 10.1% |

20 就够，30 无额外收益。**判据是两拨分位不重叠**；重叠的书（薄纸、双面重墨）只能少切或不切，硬切会连正文最淡的笔画一起没。

代价 +4MB（37.3 → 41.3MB）。这笔钱买的是曲线连续：白点同时当拉伸上锚点，白点下一级映射到 252 再跳 255；若改成拿 p80 当斜率锚点、只在白点处硬切，跳变会有 50 级，字周围会出现贴纸似的硬边。

## 别用 AI 超分（已实测，别重复走）

150 DPI 的书清晰度不够，很自然想到超分。**结论是不要用**，而且这个结论是量出来的，不是凭印象。

**验收标准不能是「看起来更锐」**：没有真值可比时，把 未 规整成 末 的模型看起来也更锐，而教材里改错字比模糊更坏——读者能看出字虚，看不出哪一笔是模型编的。

所以先造真值：拿原生 300 DPI 的书（数字信号处理教程 p61）当基准，按 150 DPI 扫描的方式降级——**高斯模糊 σ0.8 → 2× 降采样 → JPEG q68**——再还原回 300 与原页比。三个指标：PSNR、SSIM，以及决定性的那个「**字符一致**」（两边都用 `tesseract -l chi_sim+eng --psm 4` 读，对 OCR 结果算编辑距离；同一引擎读两边，测的不是 OCR 好坏，而是还原有没有改变字形）。

实测（809 字）：

| 方法 | PSNR | SSIM | 字符一致 | 改字数 |
| --- | --- | --- | --- | --- |
| **bicubic（无先验）** | **29.80** | 0.9541 | 75.53% | 198 |
| lanczos | 30.44 | 0.9562 | 71.82% | 228 |
| unsharp 120% | 30.49 | 0.9532 | 73.55% | 214 |
| Richardson-Lucy 反卷积 | 24.61 | 0.9359 | 66.87% | 268 |
| Real-ESRGAN x2 | 22.77 | 0.9385 | 76.64% | 189 |
| SwinIR x2（L1 重建） | 26.06 | 0.9462 | 70.83% | 236 |
| realesr-general x4 | 23.06 | 0.9365 | 74.91% | 203 |

三条读法：

1. **无先验方法的天花板是 75.5%**——降到 150 DPI 真的毁掉了约四分之一的字符信息，不是算法不努力。
2. **Real-ESRGAN 只换来 +1.1 个百分点（809 字里 9 个），代价是 −7dB PSNR。** 大量改像素而基本没改对，这就是幻觉的指纹。放大看 `衰` 字顶部会长出不存在的笔画：锐，且错。
3. **SwinIR 这类 L1 重建模型两项都不如 bicubic**，锐化和反卷积同样是负收益——振铃提高了 PSNR 却降低字符一致，说明「锐」和「对」是两个方向。

当时的评测脚本和权重都已删除，仓库里不留被否决路径的代码——上面那套降级配方和三个指标够重建（约 30 行 numpy/PIL）。将来真要拿新模型重测，两点别踩：推理要**分块 + 重叠融合**（一页 1000×1500，这些模型在 64px 裁片上训练，直缝会被当成断笔）；`torch` 不要进 `requirements.txt`，别让所有人为一条否决路径背 2.5GB 依赖。

## 100MB 预算该花在哪

`--max-mb` 默认 100。但**对 150 DPI 的书，多给字节买不到信息**——上采样到 300 DPI 要 95–113MB，装的还是同一份信息，只是网格更细。

余量真正的用处有两个：

- **原生 300 DPI 的大书不必再降文字 DPI。** 898 页医学教材 JBIG2 文字层 300dpi 就要 44MB，50MB 上限下阶梯会把 `--dpi` 压到 200；100MB 下可以留在 300。
- **少一层我们自己的二次压缩。** 源 JPEG 约等于 q68，我们再压一遍必然叠加损失。新能源材料与器件（150dpi + 加深 + 去背透）实测：q70 41.3MB / q80 48.5MB / q85 54.2MB / q90 63.7MB。

## 只有封面要彩色 → `--mode color`，不要手工挑页

`color` 模式是**逐页** `is_colourful()` 判定，不是整本彩色。新能源材料与器件 239 页实测只有 p1 封面和 p239 封底走彩色，正文仍是灰度，比 `gray` 模式只多 0.6MB（39.9 vs 39.3MB 层文件）。别为了留封面去写按页号分支。

## 二值化：先上采样，再用局部阈值（原生 300 DPI 才用）

文字层默认按三步切成 1-bit，三步都不要随便关：

1. **上采样到不低于 300 DPI**（`--bilevel-min-dpi`）。150 DPI 上直接切，1.5 px 宽的笔画只能落在 1 px 或 2 px 上，靠近阈值的像素被噪点左右翻转——细笔画断、密笔画粘。先重采样不增加任何信息，只是把同一份信息切在够细的网格上。
2. **轻度高斯平滑**（`--text-smooth`，单位是源像素，默认 0.3）。去掉重采样带来的锯齿和扫描颗粒，幅度远小于一个笔画宽。
3. **Sauvola 局部阈值**（`--sauvola-k` / `--sauvola-window-in`）。全局阈值分不清「淡笔画」和「深笔画周围的柔光晕」：切低了细笔画消失，切高了字腔被填满——页面对比度更高但比原灰度更难读。Sauvola 拿每个像素和它邻域的均值、对比度比，一套参数同时适配淡页和深页。空白纸上偏差项把阈值压到均值以下，颗粒仍是白的。

实测（新能源材料与器件，150 DPI 淡扫描，正文页）：旧的 150 DPI 全局阈值 200 出来 10.04% 墨量，`黑` 字腔填实、`提` 糊成块；新路径 5.6%，笔画分离。原生 300 DPI 的书（数字信号处理教程）墨量 5.23% → 5.22%，**体积不变而 `减`、`器` 不再糊**。

`--bw-threshold` 现在是逃生阀：给一个固定全局阈值，绕开 Sauvola。只有在某本书上局部阈值确实读错时才用。

### 笔画被切断 → 降 `--sauvola-k`，再考虑加 DPI

淡扫描上 k 的默认值 0.2 会把**紧邻粗笔画的淡笔画整段丢掉**：窗口里的粗笔画抬高局部对比，阈值被压得更严。症状是放大后 `岩`、`层`、`中` 这类字缺横。

新能源材料与器件 p14（450 DPI 文字层）实测，断笔指标用「墨像素中孤立端点占比」量化：

| 参数 | 墨量 | 断笔 | 观感 |
| --- | --- | --- | --- |
| k 0.20（默认） | 7.3% | 0.74‰ | 多字缺横 |
| **k 0.10** | 10.9% | **0.16‰** | 笔画完整、不糊 |
| k 0.05 | 12.9% | 0.17‰ | 开始粘连 |

同一 k 0.10 下继续加分辨率仍有收益：300 DPI 0.74‰ → 450 DPI 0.16‰ → 600 DPI 0.06‰，代价是体积 12.8 / 18.2 / 23.7MB。

**试过但没用的两条路**，别重复走：

- **二值化前反锐化**（unsharp）。过冲会在淡笔画旁边造出亮边，反而切断笔画：k 0.10 加 150% 反锐化后断笔指标从 0.16‰ 涨到 0.59‰。
- **黑顶帽谷检测 / 小窗口阈值取并集**。想法是「以紧邻像素为参考，像肉眼那样看出这一条有变深趋势」，但在 JPEG 扫描上纸面伪影同样产生谷响应；把阈值标定到真实笔画区间（谷响应 >35）后，结果与单纯 k 0.10 完全重合（墨量 10.88% vs 10.85%），没有额外信息。

### 淡扫描的正文会被误判成图片

比二值化参数更要紧的一步：`find_regions` 用「纸白像素占比」区分正文和连续色调区，而**大字号密排正文本身纸白占比就低**。新能源材料与器件在默认 `--white-level 235` 下，每页有 10–30% 的**正文**被判成图片、走 150 DPI JPEG——读者看到的就是一片灰糊的字，二值化参数再怎么调都不影响这部分。

降到 `--white-level 215` 后：正文误判归零，封面和真实插图（p73 的图表）仍被完整保护，而且**体积反而更小**（66.7 → 47.8 KB/页，JPEG 压正文比 JBIG2 贵）。

这不是普适默认值问题——同批的数字信号处理教程（2–5% 覆盖）和自动控制原理（0%）在默认值下都没有误判。判断方法：把 `find_regions` 的矩形裁出来看，**里面是字就是误判**。

## 自动调参顺序

超预算时 `plan` 固定顺序：**先降 `--photo-dpi` / `--photo-quality`，最后才 `--dpi`**。组装仍超预算会再降一档重编。

**别让它自动跑到底——先看字节花在哪。** 阶梯假设图片是大头；以正文为主的书往往相反。898 页医学教材 300dpi：JBIG2 文字层 44MB（88%），图片补丁 2.89MB（5.8%）。从 150dpi/q72 降到 75dpi/q45 只省 3MB，插图里的字全糊。这种书的大杠杆是 `--dpi`：200dpi 文字层少 15MB，中文正文仍锐利。

## 先看字节分布

跑一遍编码（不加 `--ocr`），按位深统计：

```bash
.venv/bin/python - <<'PY'
import pymupdf as fitz
d = fitz.open("out/某教材.pdf")
t = p = 0
for page in d:
    for b in page.get_image_info(xrefs=True):
        n = len(d.xref_stream_raw(b["xref"]))
        if b["bpc"] == 1: t += n      # JBIG2 文字层
        else: p += n                  # JPEG 图片补丁
print(f"text {t/2**20:.1f}MB  photos {p/2**20:.1f}MB")
PY
```

文字层占大头 → 动 `--dpi`；图片占大头 → 动 `--photo-*`。

## 主要参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--max-mb` | 100 | 体积上限（MB） |
| `--mode` | auto | `mrc` / `bilevel` / `gray` / `color`；auto 按 probe |
| `--dpi` | 原生 | 文字层 DPI |
| `--photo-dpi` | 150 | MRC 图片补丁 DPI |
| `--photo-quality` | 72 | MRC 图片补丁 JPEG 质量 |
| `--page-dpi` / `--page-quality` | — | gray/color 整页模式 |
| `--text-contrast` | 0（关） | 按页色阶加深淡墨；单调曲线，不切断笔画。会增大体积 |
| `--drop-showthrough` | 0（关） | 把比「墨纸区间的百分之几」更淡的像素压白，清背面透印；试 20 |
| `--bilevel-min-dpi` | 300 | 二值化前把文字层上采样到不低于此 DPI |
| `--text-smooth` | 0.3 | 二值化前的高斯 sigma（源像素单位）；0 关闭 |
| `--sauvola-k` | 0.2 | 局部阈值严格度；调高笔画更细，调低更饱满 |
| `--sauvola-window-in` | 0.10 | 局部阈值窗口（英寸），约一个字宽 |
| `--bw-threshold` | 关 | 逃生阀：改用固定全局阈值，绕开 Sauvola |
| `--seed-white` / `--grow-white` | 0.25 / 0.60 | 连续色调区域判定与生长 |
| `--white-level` | 235 | 多深的灰算纸白；淡色底纹常在 230 上下，降到 ~212 可让底纹回文字层 |
| `--tint-std` | 关 | 低对比大片当图片；默认关，易误伤稀疏文字 |

## 何时根本不 run

probe 报 `color`、文件已不大、图像占 97%、**或原生 DPI 只有 150** 时，**再编码只会更差**。例如 150 DPI 原生 JPEG2000 的 337 页教材 ~50MB：正确路径是只清广告（见 [ad-removal.md](ad-removal.md)），337 张图逐张 sha256 不变。

清完广告用 `pdfopt ocr` 补文本层，图像流不动。只有在读者确实抱怨发灰时才为 `--text-contrast` 付重编码的体积（见上方「扫描太淡」）。

## 页脚重复小图标（可选）

某医学教材每页页脚有「数字资源」图标（~40pt），每页一份图片补丁。原书元素但读者不看。可在扫描图上盖白矩形：实心中蓝（`B-R>25` 且灰度 110~225），跳过首末页。页码深蓝细笔画不会被误认。
