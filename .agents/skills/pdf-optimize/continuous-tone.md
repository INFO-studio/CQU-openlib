## 适用条件

当以下条件同时成立时，优先考虑 `pdfopt continuous`：

- PDF 是纯扫描件，每页恰好一张铺满页面的图像；
- 原始像素尺寸足够，主要问题是文件超过体积上限；
- 内页是黑白或双色印刷，但保留抗锯齿、浅色底纹、细工程线比保留颜色更重要；
- MRC 把浅色栏、网底、二维码或密排正文误判为图片区，导致同一页文字混用 JBIG2 与 JPEG；
- 低质量整页 JPEG 虽能命中预算，但文字边缘的振铃或糊化不可接受。

以下情况不要用：

- 页面包含多张图、矢量内容、链接、批注、透明蒙版或已有文本层；
- 正文里的颜色承载信息，不能统一转灰度；
- 需要保留交互表单、附件或复杂页面对象。

命令会主动检查这些边界。复杂页面应明确报错，不能静默丢内容。

## 为什么不用 MRC 或低质量 JPEG

### MRC 的失败判据

MRC 的前提不是“看起来像教材”，而是算法能稳定区分正文和连续色调区域。以下现象任一出现就否决 MRC：

- 没有照片的教材却在几乎每页检测到图片区；
- 同一段正文一部分变成纯黑白，一部分保持灰色；
- 浅蓝栏目、标题底纹、二维码附近形成明显的矩形编码边界；
- 放大后正文粗细或底色在矩形边界两侧跳变。

不要因为二值化部分更锐而忽略区域误判。验收对象是整页的一致性，不是孤立的几个字。

### PDF 标称 DPI 可能是错的

`probe` 的 native DPI 来自“图像像素 ÷ PDF 页面物理尺寸”。如果页面 MediaBox 写错，1888×2992 px 的清晰扫描也可能显示为约 96 DPI。遇到每页一张全幅图时，同时检查：

- 原始图像像素尺寸；
- 页面矩阵和是否铺满；
- 1:1 像素下的小字与细线；
- 是否发生了不必要的重新渲染或放大。

不要只凭标称 DPI 选择二值化或降采样。

### “降低 bit 率”要拆成两个维度

- **位深**决定一像素能表示多少灰阶。1-bit 只有黑白，会不可逆地丢掉抗锯齿；3-bit 只有 8 级灰度，可能出现层次断档；8-bit 有 256 级灰度，适合保留扫描笔画边缘。
- **码率**决定 JPEG/JPEG 2000 为每个像素分配多少数据。优先保留 8-bit 灰度，再通过 JPEG 2000 压缩倍率控制体积。

因此本路径采用 8-bit 灰度 JPEG 2000，不采用 1-bit 二值化，也不把 JPEG 质量强压到 q52。

## 工具路径

先抽样，页码应覆盖封面、版权页、普通正文、密排正文、公式、工程图、表格、二维码、附录和封底：

```bash
./pdfopt.sh continuous "原稿.pdf" \
  --pages 1-10,31,71,191,351,397,406 \
  --ratio 24 \
  --keep-first-colour 1 \
  --keep-last-colour 1 \
  --out /tmp/preview.pdf
./pdfopt.sh verify /tmp/preview.pdf
```

确认后处理全书：

```bash
./pdfopt.sh continuous "原稿.pdf" \
  --ratio 24 \
  --keep-first-colour 1 \
  --keep-last-colour 1 \
  --out "out/教材.no-ocr.pdf"
```

若需 OCR，必须从原稿识别，在压缩稿上承载文本层：

```bash
./pdfopt.sh ocr "out/教材.no-ocr.pdf" \
  --ocr-source "原稿.pdf" \
  --out "out/教材.pdf"
```

`continuous` 不修改像素尺寸，不经 PDF 页面渲染，不做阈值切割或区域检测。保留的彩色页直接复制原始编码流；其余页从原始图像转为 8-bit 灰度 JPEG 2000。

## 参数选择

`--ratio` 是 JPEG 2000 目标压缩倍率，数值越大，文件越小、损失越多：

- 先测 20、22、24、26，不要直接猜最终值；
- 从能给 PDF 结构和 OCR 留出余量的最低倍率开始；
- OCR 文本层通常只增加少量体积，但预算贴线时至少留 2%–5%；
- 若 24 已满足预算，就不要为了更小改成 28；
- 若 24 仍超预算，先判断能否减少保留彩色页，再尝试 26 或 28；不要同时改多个变量。

`--keep-first-colour N` 和 `--keep-last-colour N` 按源 PDF 页序计数。只保留确实需要颜色的封面和封底；版权页若没有颜色信息，不要因为位于书前就保留 RGB。

## 抽样验收

必须同时看整页和 1:1 像素裁切：

1. 整页检查是否缺页、裁切、旋转或改变版式。
2. 1:1 检查小字号中文的横竖笔画、公式上下标、工程图细线和表格网格。
3. 检查浅蓝底纹转灰后是否仍能区分层次。
4. 对比候选倍率时固定同页、同坐标、同显示比例。
5. 不以“更锐”为唯一标准；过锐可能来自阈值切割，正确标准是笔画和灰阶是否忠实。

缩略联系表适合找异常页，不足以判断字符损伤。最终参数必须看原像素裁切。

## 完整性检查

全书完成后至少执行：

```bash
qpdf --check "out/教材.pdf"
./pdfopt.sh verify "out/教材.pdf"
```

并核对：

- 页数与源文件一致；
- 没有解码失败页和意外空白页；
- 页面像素尺寸与源文件一致；
- 保留彩色页的原始图像流 SHA-256 一致；
- 中间页为 JPX/JPEG 2000，8-bit 灰度；
- OCR 后所有预期页可抽取文本；
- 最终体积低于上限，而不是只看抽样估算。

## 材料力学 I 实测

源文件《材料力学 I（第7版）》有 406 页、139.4MiB、无文本层、无注释、无书签，每页一张 RGB JPEG；404 页为 1888×2992 px，另 2 页为 2128×3008 px。PDF 页框导致 `probe` 报约 96 DPI，这不是判断原图质量的充分依据。

走过并否决的路径：

| 路径 | 结果 | 结论 |
| --- | --- | --- |
| MRC 96 DPI | 图像层 43.8MiB | 浅蓝栏和正文被识别成图片，同页编码不一致，否决 |
| 整页 JPEG q80 | 抽样外推约 122MiB | 超预算 |
| 整页 JPEG q52 | 抽样外推约 97MiB | 能达标但小字观感劣化，否决 |
| 8-bit 灰度 JPEG q85 | 抽样外推约 128MiB | 去色不足以消除纸张纹理成本 |
| 8 级灰度无损 PNG | 抽样外推约 84MiB | 只有 3-bit 灰阶，层次断档风险高，作为备选 |
| 8-bit 灰度 JPEG 2000 22:1 | 图像外推约 99.9MiB | 没有 OCR 和结构余量 |
| **8-bit 灰度 JPEG 2000 24:1** | **图像 91.2MiB，OCR 后 91.95MiB** | **采用** |

最终结果保留第 1、406 页原始彩色 JPEG，404 个内页为灰度 JPX；页数和像素尺寸不变，封面与封底图像流哈希一致。OCR 使用原始 139.4MiB 扫描作为识别源，共写入 9697 行文本。`qpdf --check` 和 406 页逐页解码均通过。
