# 生成与校验目录书签

没有书签的教材交付前必须补全书签（封面/书名页/版权页/前言/目录 + 完整正文目录 + 参考文献/封底）。原书已有干净书签时，`run` 与 `continuous` 会自动保留；已有广告书签按 [ad-removal.md](ad-removal.md) 过滤

## 为何不用目录页 OCR 直接正则抽取

目录页布满密集点线（`…………`），Tesseract 容易把点线与数字混成乱码（如 `建筑平面图` 错成 `es 43`）。稳定做法是**视觉读清晰目录页图 + `pdfopt toc apply` 确定性解析、偏移核验与无损写入**

## 标准步骤

### 1. 导出前置与目录页图

```bash
./pdfopt.sh toc pages "out/教材.pdf" --pages 1-16 --out-dir /tmp/toc_pages
```

从导出图像中确认两件事：

- **完整目录层级**：章、节、小结/复习思考题及其印刷页码，以及前置页（封面、书名页、版权页、前言、目录）和末页（参考文献、封底）的 PDF 实际页码
- **页码偏移 `--offset`**：`正文第 1 页的 PDF 物理页码 − 1`（如正文第 1 页在 PDF 第 10 页，则 `--offset 9`）

### 2. 写成缩进文本并写入

- 缩进表达层级（任意一致的 2/4 空格或 Tab）
- 前置/后置页写 `@<PDF绝对页码>`（不受 `--offset` 影响）；正文目录写书内印刷页码，自动加上 `--offset`

```bash
./pdfopt.sh toc apply "out/教材.pdf" --from - --offset 9 --page-labels <<'EOF'
封面 @1
书名页 @2
版权页 @3
前言 @4
目录 @6
1 建筑概论 1
  1.1 中国建筑的起源和发展 1
  1.2 外国建筑的起源和发展 11
参考文献 395
封底 @405
EOF
```

- `--page-labels` 会把前置页设为小写罗马数字（`i, ii...`）、正文第 1 页起设为阿拉伯数字（`1, 2...`），与书籍印刷页码一致
- `toc apply` 通过 `pikepdf` 只更新 Outline 与 `/PageLabels` 并线性化保存，**图像流与 OCR 文本层零改动**

### 3. 核验偏移与产物

- 若目标 PDF 已有 OCR 文本层，`toc apply` 会抽样比对二级标题在 `offset`、`offset - 1`、`offset + 1` 的命中率，若相邻偏移命中更高会告警（加 `--strict` 可直接中止）
- 写入后自动执行 `verify`，也可用 `./pdfopt.sh toc show "out/教材.pdf"` 复查书签树与逻辑页码标签
