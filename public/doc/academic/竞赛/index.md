# 学科竞赛

!!! info "说明"
    本板块整理官网通知通常不会写明的参赛体验与准备建议。比赛安排和规则会随届次变化，请以 [重庆大学学生交叉创新中心](https://sxic.cqu.edu.cn/home) 发布的当届通知为准。

## 参赛前

- **先确认认可规则**：分别查看教育部竞赛名单、学校通知和所在学院的评奖、综测或推免细则。进入某份名单不等于在所有学院获得相同认定。
- **预留连续投入时间**：竞赛通常包含培训、方案迭代、材料整理和集中冲刺。报名前应确认自己能承担的时间与职责。
- **先做小规模验证**：在正式报名之前共同完成一道题、一个原型或一页方案，可以比口头承诺更有效地判断协作方式。

## 找队友

可加入竞赛组队 QQ 群：`1085840265`。

组队时优先确认以下事项：

1. **投入是否稳定**：直接讨论每周可投入时间、冲突时如何交接，以及独立推进任务的意愿。
2. **能力是否互补**：非专业限制赛事可考虑跨专业组队，例如机械、电控、视觉、硬件和宣传等方向相互配合。
3. **经验是否互补**：跨年级队伍可以同时利用高年级经验和低年级较充足的时间。
4. **规则是否提前说清**：在报名之前约定分工、节点、成果署名、排序依据和退出机制，出现问题时按约定处理。
