# 加入运维小组

重庆大学资源共享计划 openlib 为重庆大学学生以非官方学生团体身份筹划、发布、更新的资源整合站点，旨在打破信息壁垒，持久化保留一众口口相传的校内相关资源及信息。站点的内容开发、内容更新与请求响应由 openlib 运行维护小组承担

我们想请更多同学一起来做这件事

## 职能

- **开发**：本站使用 Vite + React + TanStack Router SPA + Serverless Functions + MongoDB + 对象存储。千页级别搜索、Markdown 解析器、地图、表单等等功能均手搓实现
- **内容**：收录教材、试卷、课件，核课程号，把群里口口相传的东西写成能被检索复用的页面
- **运营**：答疑、对接社团与学生团体，判断资源可靠性

## 给你什么

- [贡献者](../contributor/index.md) 栏的个人页，每条改动进 [更新日志](更新日志/index.md)，公开可查
- git、PR、review 跑在真有人用的项目上，完整的开发维护/内容运营流程，千级日活、万级项目真实用户
- 想加栏目自己提、自己做，鼓励符合大方向预期的任何创新

## 不会有什么

- 不是官方社团：没有证书、没有盖章、写不进官方任职经历
- 不算二课积分、不算志愿时长、不算综测加分
- 没有报酬（可以有必要报销），站点不接推广，也不做付费内容
